Cara Kerja

Lima langkah, selesai

Setup sebentar, scan dulu, lalu optimalkan yang memang perlu — tidak lebih.

1

Install Extension

Pasang extension Chrome. Kurang dari satu menit.

2

Masukkan API Key

Ikuti panduan pembuatan API Key lalu tempel ke extension.

3

Buka Pending Files

Masuk ke halaman pending-files Magnific untuk aset yang akan diproses.

4

Scan Metadata

Klik Scan — setiap gambar langsung dinilai dengan skor 0–100 tanpa memakai API.

5

Optimalkan yang Lemah

Klik Optimalkan — AI hanya memproses gambar yang skornya kurang. Yang sudah bagus di-skip otomatis.

Fitur

Apa yang ada di dalamnya

Dibuat khusus mengikuti workflow Freepik (Magnific).

Scan Metadata

Cek skor kualitas semua gambar sekaligus tanpa memakai API. Setiap gambar dinilai 0–100 dan dikategorikan: ready, improve, atau review.

Optimize Mode

Hanya proses gambar yang skornya lemah. Gambar yang sudah bagus di-skip otomatis — hemat biaya API secara signifikan.

Forbidden Word Filter

Kata format file (EPS10, JPG, PNG, PSD, SVG, PDF) dan kata generik (image, photo, stock) diblokir otomatis dari title dan keywords.

Duplicate Title Guard

Saat upload aset serupa sekaligus, extension memastikan tidak ada title yang persis sama antar gambar.

GPT-4o Vision

Analisis visual tiap gambar untuk menghasilkan title dan keyword yang relevan dengan isi sebenarnya.

Triple Filter + Counter-Aware

Hanya memproses item upload asli di grid. Pakai counter resmi Magnific sebagai sumber kebenaran jumlah keyword.
